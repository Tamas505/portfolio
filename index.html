Rólam

56 évesen döntöttem úgy, hogy új szakmát tanulok, és a webfejlesztésben találtam meg azt a területet, ahol igazán otthon érzem magam. Erősségeim a kitartás, a precizitás, és az, hogy szeretek mélyen megérteni minden technológiát, amivel dolgozom, nem csak használni őket. A frontend alapokat (HTML, CSS, Bootstrap, JavaScript, TypeScript, Angular) már elsajátítottam, jelenleg pedig a backend fejlesztés felé haladok, különösen PHP és MySQL területen. Saját projektekben már alkalmazom a backend logikát és az adatbázis-kezelést. Célom, hogy junior fejlesztőként egy támogató csapatban dolgozhassak, ahol értéket teremthetek és folyamatosan fejlődhetek.

Technológiák, amikkel dolgozom

  • HTML5, szemantikus struktúra
  • Modern CSS (flexbox, grid, reszponzív layoutok)
  • Bootstrap
  • JavaScript, TypeScript
  • Angular – komponensek, űrlapkezelés, validáció
  • PHP – backend logika, űrlapfeldolgozás
  • MySQL – adatbázis-kezelés, lekérdezések
  • CRUD műveletek (Create, Read, Update, Delete)
  • Git és GitHub, VS Code
  • Eleventy (11ty) – statikus site generátor
  • Nunjucks sablonnyelv
  • Markdown – tartalomkezelés
  • GitHub Pages publikálás
