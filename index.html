Rólam

56 évesen döntöttem a pályaváltás mellett, és a webfejlesztésben találtam meg azt a területet, ahol igazán otthon érzem magam. Erősségeim a kitartás, a precizitás és a rendszerszemlélet.

Frontend technológiákkal (HTML, CSS, JavaScript, Angular) már magabiztosan dolgozom, jelenleg pedig backend irányban (PHP, MySQL) bővítem a tudásomat. Saját projektjeimben már valós adatkezelést és backend logikát is alkalmazok.

Projektjeim valós problémák megoldására épülnek, és a gyakorlati tudásomat tükrözik.

Célom, hogy fejlesztőként egy csapatban dolgozhassak, ahol értéket teremthetek és tovább fejlődhetek.

Technológiák, amikkel dolgozom

  • HTML5, szemantikus struktúra
  • Modern CSS (flexbox, grid, reszponzív layoutok)
  • Bootstrap
  • JavaScript, TypeScript
  • Angular – komponensek, űrlapkezelés, validáció
  • PHP – backend logika, űrlapfeldolgozás
  • MySQL – adatbázis-kezelés, lekérdezések
  • CRUD műveletek (Create, Read, Update, Delete)
  • Git és GitHub, VS Code
  • Eleventy (11ty) – statikus site generátor
  • Nunjucks sablonnyelv
  • Markdown – tartalomkezelés
  • GitHub Pages publikálás
  • PDO – biztonságos adatbázis-kezelés prepared statementekkel
  • MVC alapok (Model–View–Controller)
  • REST API alapok, Fetch API, AJAX
  • Űrlapvalidáció (HTML5 és szerveroldali ellenőrzés)
  • Email küldés PHP-val
  • XAMPP fejlesztői környezet
